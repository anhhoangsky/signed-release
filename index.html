MNG Cloud signed releases

This branch hosts only signed release metadata. The Trusted Security Extension verifies it independently of the cloud origin.

  • releases/current/release.json
  • releases/current/release.sig
  • releases/current/manifest.json
  • releases/current/manifest.sig

Signatures use ECDSA P-256/SHA-256. The public key is pinned in the extension build; this site is only transport.
